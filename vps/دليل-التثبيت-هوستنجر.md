# دليل تشغيل «كليب كات» على سيرفر Hostinger VPS — خطوة بخطوة

هذا الدليل لمن لا يملك خبرة تقنية. ستحتاج حوالي **30 دقيقة**. في النهاية يصبح لديك موقع كليب كات على سيرفرك أنت: تسجيل دخول حقيقي، رفع مقاطع، متاجر، ولوحة مشرف.

> 🔒 **قاعدة ذهبية:** لا ترسل كلمة مرور السيرفر أو ملف `.env` لأي شخص أو موقع.

## ما الذي تحتاجه؟

| الشيء | ملاحظة |
|---|---|
| سيرفر Hostinger VPS | الأفضل **KVM 2** (انظر «الحجم المناسب» أسفل الدليل) |
| ملف `clipkat-vps.zip` | الحزمة التي استلمتها |
| نطاق (دومين) | اختياري للتجربة، **مهم جداً** للاستخدام الحقيقي (لتشفير HTTPS وحماية كلمات المرور) |
| جهاز كمبيوتر ويندوز / ماك | لرفع الملف |

---

## الخطوة 1 — جهّز السيرفر في Hostinger

1. ادخل إلى **hPanel** ← قسم **VPS** ← اضغط **Manage** (إدارة) على السيرفر.
2. إن كنت تنشئ سيرفراً جديداً أو تعيد تثبيته: اختر نظام التشغيل **Ubuntu 24.04** وهو النظام العادي (**Plain OS**).
   ⚠️ **لا تختر** قوالب فيها برامج جاهزة (لوحات تحكم، WordPress، Docker جاهز…). نحتاج Ubuntu نظيفاً فقط — السكربت يثبّت Docker بنفسه.
3. اكتب **كلمة مرور root** قوية واحفظها.
4. من صفحة **Overview** (نظرة عامة) انسخ **عنوان IP** للسيرفر (أرقام مثل `123.45.67.89`). سنسميه **IP** في بقية الدليل.

## الخطوة 2 — افتح الطرفية (Terminal)

الأسهل: في صفحة السيرفر اضغط الزر **Browser terminal** (طرفية المتصفح) أعلى الصفحة. تفتح شاشة سوداء تكتب فيها الأوامر.

(بديل: من ويندوز افتح **PowerShell** واكتب `ssh root@IP` ثم كلمة المرور.)

> 💡 لصق الأوامر: انسخ السطر ثم الصقه في الطرفية (كليك يمين أو Ctrl+Shift+V) ثم اضغط **Enter**.

## الخطوة 3 — ارفع ملف الحزمة إلى السيرفر

افتح **PowerShell** على جهازك (ليس طرفية السيرفر) في المجلد الذي فيه `clipkat-vps.zip` ونفّذ (غيّر `IP`):

```
scp clipkat-vps.zip root@IP:/root/
```

اكتب `yes` إن سُئلت، ثم كلمة مرور السيرفر. (برنامج **WinSCP** أو **FileZilla** يفي بالغرض أيضاً: اسحب الملف إلى مجلد `/root`.)

**بديل:** إن رفعت الملف إلى رابط تحميل مباشر، نفّذ في طرفية السيرفر: `wget -O clipkat-vps.zip "الرابط"`

## الخطوة 4 — (اختياري لكن موصى به) اربط النطاق بالسيرفر

اجعل هذه الخطوة **قبل** التثبيت حتى يعمل HTTPS من أول مرة.

1. في hPanel ← **Domains** ← اختر نطاقك ← **DNS / Nameservers** ← **DNS records**.
2. أضف سجلاً جديداً:

| Type | Name | Points to | TTL |
|---|---|---|---|
| **A** | `@` (أو اسم فرعي مثل `clip`) | **IP** السيرفر | 300 |

3. احذف أي سجل **A** قديم لنفس الاسم (صفحة «قيد الإنشاء» التي تضعها الشركة) وأي سجل **AAAA**.
4. انتظر 5–30 دقيقة. إن لم يكن لديك نطاق الآن فتجاوز هذه الخطوة، وسيعمل الموقع على `http://IP` (بدون تشفير — للتجربة فقط).

## الخطوة 5 — ثبّت (أمر واحد)

في طرفية السيرفر اكتب الأوامر التالية سطراً بسطر:

```
apt-get update && apt-get install -y unzip
unzip clipkat-vps.zip
cd clipkat-vps
bash install.sh
```

سيسألك السكربت:

1. **اسم النطاق** — اكتب مثل `clip.example.com` أو اتركه فارغاً (للعمل على IP).
2. **بريد المشرف** — بريدك، وبه ستدخل إلى لوحة الإدارة.
3. **بريد شهادة HTTPS** — يقترح بريد المشرف؛ اضغط Enter.
4. **كلمة مرور المشرف** — اكتب كلمة قوية (8 أحرف فأكثر)، أو اتركها فارغة وسيولّد السكربت واحدة ويطبعها لك. **احفظها فوراً.**

ثم يعمل وحده: يثبّت Docker، يولّد كلمات سر عشوائية، يشغّل الموقع، يفعّل الجدار الناري (المنافذ 22 و80 و443 فقط) ويجهّز **نسخاً احتياطية يومية**. يستغرق **5–10 دقائق**.

في النهاية تظهر رسالة فيها ✅ والرابط النهائي، مثل: `https://clip.example.com`

## الخطوة 6 — جرّب الموقع

1. افتح الرابط في المتصفح (إن كان النطاق جديداً وظهر تحذير شهادة فانتظر دقائق وأعد المحاولة).
2. اضغط **دخول** وادخل ببريد المشرف وكلمة مروره ← يظهر زر **لوحة الإدارة** في ملفك الشخصي.
3. أنشئ حساباً عادياً آخر (من نافذة خفية) وجرّب: **رفع مقطع**، **إعجاب**، **تعليق**، **متابعة**.
4. جرّب **تأجير متجر** بحساب عادي: بعد «الدفع» التجريبي تظهر الحالة **«قيد الانتظار»** ← هذا طبيعي.
5. ادخل بحساب المشرف ← **لوحة الإدارة** ← اضغط **تفعيل** بجانب الإيجار ← يصبح المتجر نشطاً ويظهر في صفحة المتاجر.

> ℹ️ **لماذا الإيجار «قيد الانتظار»؟** لأن التفعيل التلقائي يجب أن يأتي من بوابة الدفع الحقيقية (Tap أو MyFatoorah)، وهذا الربط **لم يكتمل بعد** (هيكل أولي موجود). المتصفح لا يستطيع تفعيل أي إيجار — فقط المشرف. فعّل الإيجارات يدوياً بعد أن تستلم المبلغ بنفسك حتى يُربط الدفع.

## إضافة مشرف آخر

اكتب في الطرفية (من داخل مجلد `clipkat-vps`)، بعد أن يسجّل ذلك الشخص حساباً:

```
cd /root/clipkat-vps
docker compose exec db psql -U clipkat -d clipkat -c "update profiles set is_admin=true where lower(email)=lower('البريد@example.com')"
```

## نسيت كلمة المرور؟

لا يوجد إرسال بريد في هذه النسخة (لا «نسيت كلمة المرور» تلقائي). المشرف يغيّرها من الطرفية:

```
cd /root/clipkat-vps
docker compose exec app node server/src/cli-reset-password.js البريد@example.com 'كلمة-جديدة-قوية'
```

## النسخ الاحتياطي (مهم)

- **تلقائي:** كل يوم 03:30 فجراً تُحفظ نسخة (قاعدة البيانات + المقاطع والصور) في مجلد `/root/clipkat-vps/backups` ويُحتفظ بآخر 14 يوماً.
- **يدوي الآن:** `cd /root/clipkat-vps && ./backup.sh`
- **حمّل نسخة إلى جهازك** من وقت لآخر (من PowerShell على جهازك):
  `scp -r root@IP:/root/clipkat-vps/backups .`
  (النسخ على نفس السيرفر لا تحميك إن تعطّل السيرفر نفسه. Hostinger توفّر أيضاً نسخاً أسبوعية من لوحتها — فعّلها.)
- **استرجاع:** `cd /root/clipkat-vps && ./restore.sh backups/clipkat-التاريخ` ثم اكتب `YES`.
  ⚠️ يستبدل كل بيانات الموقع الحالية بالنسخة.

## التحديث

عندما تستلم حزمة جديدة: ارفعها إلى السيرفر ثم:

```
cd /root/clipkat-vps
./update.sh /root/clipkat-vps-جديد.zip
```

يأخذ نسخة احتياطية أولاً ويحافظ على بياناتك وإعداداتك.

## حل المشاكل

| المشكلة | الحل |
|---|---|
| الموقع لا يفتح على IP | في hPanel ← VPS ← **Security / Firewall**: إن كان جدار Hostinger مفعّلاً، افتح المنافذ **22 و80 و443**. |
| HTTPS لا يعمل / تحذير شهادة | تأكد أن سجل **A** يشير إلى IP الصحيح (وحذف سجل AAAA)، وانتظر 10–30 دقيقة. افحص: `docker compose logs caddy` |
| يظهر الموقع بوضع «نسخة تجريبية» محلي | التطبيق لا يعمل: `docker compose ps` ثم `docker compose logs app` |
| «محاولات كثيرة» عند الدخول | حماية تلقائية: انتظر 15 دقيقة. |
| رفع الفيديو يفشل «كبير جداً» | الحد الافتراضي 100MB؛ ارفعه من `.env` (انظر الأعلى) أو اضغط الفيديو قبل الرفع. |
| امتلأ القرص | `df -h` — احذف نسخاً قديمة من `backups/` أو رقِّ السيرفر. |
| أخطأت أثناء التثبيت | يمكنك تشغيل `bash install.sh` مرة أخرى بأمان؛ لا يغيّر الأسرار ولا يحذف بياناتك. |

## ملاحظات مهمة

- **نظام التشغيل:** Ubuntu 24.04 عادي (Plain OS). **المنافذ المفتوحة:** 22 (للدخول) و80 و443 (للموقع) فقط، وقاعدة البيانات غير مكشوفة للإنترنت.
- **بدون نطاق = بدون تشفير:** كلمات المرور تُرسَل بلا HTTPS. استخدم نطاقاً للإنتاج.
- **الدفع تجريبي:** لا يُخصم أي مبلغ. الربط الحقيقي مع Tap/MyFatoorah لم يكتمل.
- **لا يوجد بريد إلكتروني:** لا تأكيد بريد ولا «نسيت كلمة المرور» (انظر أعلاه).
- **الفيديو الطويل والزوار الكثيرين:** المقاطع تُخدم من قرص السيرفر نفسه وتستهلك سرعة الشبكة. عند نمو الموقع، الخطوة التالية هي نقل الفيديو إلى **Cloudflare Stream** (يتولى الضغط والتوزيع حول العالم) ويحتاج تعديلاً برمجياً لاحقاً.
- **الاسم:** اسم «ClipKat / كليب كات» قريب من علامات موجودة (KitKat) — لم يتغير التنبيه: راجع الاسم قانونياً قبل أي إطلاق تجاري.
- **الرخصة:** جميع الحقوق محفوظة (ملف `LICENSE`).

## الحجم المناسب للسيرفر (Hostinger)

| الخطة | المواصفات | تناسب |
|---|---|---|
| KVM 1 | 1 vCPU · 4GB RAM · 50GB NVMe | تجربة وعشرات المستخدمين (مساحة المقاطع تنفد بسرعة) |
| **KVM 2 ⭐** | 2 vCPU · 8GB RAM · 100GB NVMe | **البداية الموصى بها** — مئات المستخدمين وآلاف المقاطع الصغيرة |
| KVM 4 | 4 vCPU · 16GB RAM · 200GB NVMe | نمو أكبر أو مقاطع كثيرة |

القرص هو أول ما ينفد (كل مقطع 10–50MB). يمكن الترقية لاحقاً من لوحة Hostinger دون فقد البيانات.
